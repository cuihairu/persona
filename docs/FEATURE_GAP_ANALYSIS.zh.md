## 分域明细

- 安全（Security）
  - 端到端加密、零知识：[=] per-item key 由主密钥包裹（AES-256-GCM）；导出/备份加密使用 Argon2id；旧版直接加密行仍可读取
  - SRP 认证模型：[=] 服务端流程 2026-09 落地：RFC 5054 SRP-6a（4096 位群），设备认证（`/api/v1/auth/*`）与账号域（`/api/v1/accounts/*/srp/*`）双侧均带 Argon2id 预哈希；客户端在 `core/src/auth/srp.rs`，锁定 RFC 5054 测试向量
  - 生物识别解锁：[=] 三桌面平台原生接线落地（Linux polkit `auth_self` / macOS LocalAuthentication / Windows Hello；主密码托管在 OS keyring，InvalidCredentials 当场清除条目，OS provider 不可用时 fail-closed——2026-09）
  - 自动锁定策略：[=] 自动锁定计时器 + 敏感操作重认证
- 保险库/条目（Vaults/Items）
  - 多保险库/集合：[−] 设计为单 workspace（按 identity 划域）；多用户保险库功能明确出界（见 `BOUNDARY.md`）
  - 条目类型：[≈] password、API key、TOTP、SSH key、bank card、server config、digital certificate、game account、加密钱包占位；secure note 作为一等加密条目类型（`CredentialData::SecureNote`，正文在 per-item key 之下——2026-09）；Identity + Software License 类别（证件号 / 许可证密钥在 per-item key 之下，2026-09）
  - Passkey（FIDO）：[=] core/CLI 内软件认证器（ES256，per-item-key 包裹存储），浏览器桥拦截带审批门禁（协议 v2），桌面管理页 + Unix socket 审批服务器；跨设备同步已在端到端加密同步轨落地（语义快照 + item-key 重包；sign_count/last_used 保持设备本地）；OS 平台认证器（macOS/Windows）仍待做
  - 附件/版本管理：[=] 附件完全落地（文件密封在所属条目的 per-item key 下，主密码轮换后存活，随条目级联删除；桌面面板带原生文件对话框 + `persona credential attach/attachments/save-attachment/remove-attachment` CLI，2026-09）；条目变更历史在每次创建/更新/删除时记录，仅元数据级字段 diff，在桌面详情面板与 `persona credential history` 呈现（2026-09）；按版本恢复对元数据落地（core `restore_credential_version`、`persona credential restore --id --version`、桌面历史时间线 Restore 按钮——2026-09-22）；密文字段不做版本：历史快照永不含密文（密码/密钥回滚需要快照存储 + 密文重放风险一轮评估）
- 自动填充与浏览器（Autofill & Browser）
  - 浏览器扩展：[≈] Chromium 扩展 + Native Messaging 桥 MVP（用户名/密码填充、TOTP verb、配对 + HMAC + origin 绑定 + user gesture、域名策略、防钓鱼）；Safari host 外壳已在
  - 银行卡填充：[x] 桥协议 + 扩展接线完成（2026-09-22）：`get_suggestions` 接受 `form_type`（默认 "login" / "card" → 所有 active BankCards，不过滤 URL，`match_strength` 100）；`request_fill` 接受 BankCard 并返回 `card` 载荷（**CVV 永不出现在填充响应中**——填充目标是页面脚本可读的页面 DOM，CVV 仅可复制）；`copy` 接受 `card_number`/`cardholder_name`/`expiry_date`/`cvv`（空字段被拒）；扩展 formScanner 归类四种卡角色（autocomplete `cc-*` token + 去符号化姓名提示，刻意排在 TOTP 启发式之前，以免 `cc-csc`/`cc-exp` 被吞掉；`security code`/`verification code` 仍是 TOTP 标签）；popup 渲染卡行并带填充（页面侧填充按设计跳过 `card_cvv`）+ 复制动作
  - TOTP 自动填充：[x] 桥协议 + 打磨过的页内 UX（2026-09-22）：focus 自动填充、6 格数字分组填充、登录填充后链式填充（`autoFillTotpAfterLogin` 设置）、陈旧码窗口（≤3s）等满周期后重取一次、填充/复制提示携带剩余秒数、多候选自动填充改为打开内联选择器而非静默失败（per-origin 默认记忆不变）；注入控件的 Shadow-DOM 隔离于 2026-09-22 落地（单一 closed shadow root，keyframes 移出 `document.head`）；剩余跟进：内联码展示控件（刻意不做——页面脚本可读 content-script DOM）
