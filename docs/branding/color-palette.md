# Color Palette

> [English](color-palette.md) | [中文](color-palette.zh.md)

Core colors

- Primary (brand primary)
  - Hex: `#4C6FFF` (Indigo 500)
  - Used for: buttons, emphasis, links, icon strokes
- Accent (highlight secondary)
  - Hex: `#00D1B2` (Teal / Mint)
  - Used for: highlights, gradient pairing, success-state support

Semantic colors

- Success: `#10B981` (green)
- Warning: `#F59E0B` (orange)
- Danger: `#EF4444` (red)
- Info: `#3B82F6` (blue)

Neutrals (light mode first)

- Text Primary: `#0F172A` (dark blue-gray)
- Text Secondary: `#334155`
- Border: `#E2E8F0`
- Background: `#FFFFFF`
- Surface: `#F8FAFC`

Dark mode suggestions

- Text Primary: `#E2E8F0`
- Text Secondary: `#CBD5E1`
- Border: `#1F2937`
- Background: `#0B1220`
- Surface: `#111827`

Gradient (recommended)

- Direction: top-left → bottom-right
- Stops: `#4C6FFF` → `#00D1B2`

Contrast advice

- Text/background contrast ≥ 4.5:1
- Secondary text / disabled states may relax to 3:1, but not for critical information
