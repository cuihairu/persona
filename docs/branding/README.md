- docs/branding/logo.svg 主 Logo（矢量，取景框 + 人像，2026-09-26 由用户图标替换）

- 文档页眉、站点导航等使用 `wordmark-horizontal.svg`。
- 颜色取值参见 `color-palette.md`，注意深浅模式下的对比度。
